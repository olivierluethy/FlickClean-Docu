# FlickClean Docu

Design documentation and screen mockups for **FlickClean Photo Cleaner**, a
swipe-based mobile app concept for cleaning up your camera roll on iPhone and iPad.

This repository holds the visual assets only (the source Figma file and exported
screenshots) — there is no application code here.

## Contents

- `FlickClean Photo Cleaner Screenshots.fig` — the source Figma design file.
- `iPhone/` and `iPad/` — exported screenshot sets (1–5) for each form factor.
- `iPhone.zip` / `iPad.zip` — zipped copies of the screenshot sets.
- Additional standalone screenshots (`.jpg` / `.png`).
- `deepl-pdf-convert_translated.pdf` — a translated supporting document.

## Usage

Open the `.fig` file in [Figma](https://www.figma.com) to explore the full design,
or browse the `iPhone/` and `iPad/` folders to view the exported screens.
